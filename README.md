# Умный Шопинг

Интеллектуальный помощник для поиска и сравнения товаров.

Пользователь описывает, что ему нужно, например: «Смартфон с хорошей камерой и быстрой зарядкой до 50 000 рублей». Сервис находит магазины, собирает предложения, считает доставку в регион пользователя и выдаёт персональную рекомендацию с объяснением, почему этот вариант лучший.

> Проектный практикум УрФУ, осенний семестр 2026/2027. Заказчик: УТП ООО.

## Идея проекта

Информация о цене, наличии, доставке и условиях покупки разрознена, а самая низкая цена не всегда означает лучшую покупку. «Умный Шопинг» оценивает предложения не только по цене, но и по комплексному **индексу выгоды**: итоговая цена (товар + доставка), срок доставки, рейтинг продавца, гарантия, условия возврата, наличие. Веса показателей зависят от приоритетов пользователя.

Цепочка работы сервиса:

```
запрос → поиск магазинов → агрегация предложений → расчёт доставки → рекомендация с объяснением
```

## Возможности (MVP)

| Модуль | Что делает |
|---|---|
| M1. Аккаунт и профиль | Регистрация, вход, регион доставки, приоритеты выбора |
| M2. Поиск | Запрос на естественном языке или по названию/артикулу, состояния поиска |
| M3. Источники и агрегация | Адаптеры минимум для 3 площадок, нормализация, склейка товаров, кэш |
| M4. Доставка | Стоимость и срок доставки по региону для каждого предложения |
| M5. Рекомендации | Индекс выгоды, лучший вариант, топ-3 альтернатив, текстовое объяснение |
| M6. Дашборд сравнения | Таблица предложений с сортировкой, фильтрами и карточкой предложения |
| M7. Избранное и отслеживание | Избранное, отслеживание цены, уведомления о снижении |
| M8. Отзывы и рейтинги | Рейтинг продавца, приведённый к единой шкале |

Функции Should и Could (история, график цены, сравнение характеристик, мобильная версия и др.) реализуются после MVP.

## Критерии приёмки

- Поиск находит не менее 3 релевантных площадок.
- Для каждой площадки собираются цена, наличие и рейтинг продавца.
- Доставка рассчитывается автоматически с учётом региона.
- Формируется персонализированная рекомендация.
- Дашборд показывает таблицу с сортировкой и фильтрами.
- Работают избранное и уведомления об изменении цены.
- Время обработки запроса не превышает 10 секунд.
- Не менее 60% тестовых пользователей отмечают, что рекомендация помогла выбрать лучший вариант.

## Технологии

Стек предварительный, уточняется командой:

- **Бэкенд:** Python (FastAPI) или Node.js (NestJS)
- **Фронтенд:** React + TypeScript (адаптивный SPA/PWA)
- **Хранилища:** PostgreSQL, Redis
- **Инфраструктура:** Docker, CI/CD
- **Дизайн:** Figma

## Работа с Git

**Ветки**

- `main` — стабильная версия для показа куратору
- `develop` — рабочая ветка
- `feature/<ID>-<кратко>` — ветки задач, например `feature/M1.1-auth`

**Коммиты и Pull Request**

В начале сообщения указываем ID функции из плана:

```
M1.1: добавлена регистрация и вход по email
```

Слияние в `develop` и `main` выполняется через Pull Request минимум с одним подтверждением (code review).
