# Шаблоны объяснения рекомендации

**Проект:** Умный Шопинг
**Функция:** M5.3 (объяснение «почему это лучший вариант»)
**Связанные требования:** FR-8, критерий заказчика «обоснованная рекомендация»
**Связанный документ:** `docs/analysis/benefit_index_draft.md` (методика индекса выгоды)
**Автор:** Клейн А.Н.
**Дата:** 23.11.2026
**Статус:** шаблоны для реализации без LLM; пороги помечены «предложено»

## 1. Принципы

1. **Только факты из данных.** Объяснение строится из значений предложения и выдачи, ничего не придумывается.
2. **Не более трёх причин.** Выбираются самые сильные стороны рекомендованного предложения.
3. **Честность о недостатках.** Если рекомендованное предложение дороже самого дешёвого, это говорится прямо.
4. **Оговорки о качестве данных.** Оценочная доставка и отсутствие рейтинга отмечаются в тексте.
5. **Простой язык.** Без терминов «индекс», «нормализация»; числа округляются до целых (рейтинг до десятых).

## 2. Переменные

| Переменная | Значение |
|---|---|
| `{магазин}` | название продавца |
| `{итого}` | итоговая цена с доставкой, ₽ |
| `{срок}` | максимальный срок доставки, дней |
| `{доставка}` | стоимость доставки, ₽ |
| `{рейтинг}` | рейтинг продавца 0–5 |
| `{гарантия}` | срок гарантии, месяцев |
| `{N}` | процент отличия цены |
| `{разница}` | разница в рублях |
| `{число}` | число предложений в выдаче |

## 3. Расчёт сравнений

- **Сравнение со средним:** `N = (среднее_итого_остальных − итого) / среднее_итого_остальных × 100`, округление до целого. Фраза «дешевле на N%» используется при N не менее 3.
- **Сравнение с самым дешёвым:** `разница = итого − минимальное_итого`, `N = разница / минимальное_итого × 100`. Фраза «дороже самого дешёвого на {разница} ₽ ({N}%)» используется, если рекомендованное предложение не самое дешёвое.
- **Самое быстрое:** срок рекомендованного равен минимальному в выдаче и меньше максимального.
- **Лучший рейтинг:** рейтинг равен максимальному в выдаче при наличии рейтинга у хотя бы двух предложений.
- **Лучшая гарантия:** гарантия равна максимальной в выдаче и больше минимальной.

## 4. Выбор причин

Причины проверяются по порядку и берутся первые три подходящие:

| Приоритет | Причина | Условие |
|---|---|---|
| 1 | самая низкая цена | итого равно минимальному |
| 2 | самая быстрая доставка | см. раздел 3 |
| 3 | лучший рейтинг | см. раздел 3 |
| 4 | лучшая гарантия | см. раздел 3 |
| 5 | бесплатная доставка | стоимость доставки равна 0 |
| 6 | цена ниже среднего | N не менее 3 |

Если подходящих причин нет, используется шаблон «сбалансированное предложение» (раздел 5, Т7).

**Порядок для режима пользователя (предложено):** при выбранном пресете «Быстрее» причина «быстрая доставка» проверяется первой, при «Дешевле» первой проверяется «низкая цена», при «Надёжнее» первыми проверяются «рейтинг» и «гарантия». Так объяснение отражает то, что важно пользователю.

## 5. Шаблоны

**Структура:** заголовок + причины + сравнение + оговорка.

| № | Шаблон | Когда используется |
|---|---|---|
| Т1 | `Рекомендуем {магазин}: {причина 1}, {причина 2} и {причина 3}.` | основной, три причины |
| Т2 | `Рекомендуем {магазин}: {причина 1} и {причина 2}.` | две причины |
| Т3 | `Рекомендуем {магазин}: {причина 1}.` | одна причина |
| Т4 | `Оно дороже самого дешёвого варианта на {разница} ₽ ({N}%), но по сочетанию цены, срока и надёжности подходит лучше всего.` | рекомендованное не самое дешёвое |
| Т5 | `Цена с доставкой на {N}% ниже средней по остальным предложениям.` | N не менее 3 и рекомендованное самое дешёвое |
| Т6 | `Стоимость доставки оценочная.` | `is_estimate = true` |
| Т7 | `Рекомендуем {магазин}: предложение лучше всего сочетает цену, срок и надёжность продавца.` | нет сильной стороны |
| Т8 | `Рейтинг продавца неизвестен.` | рейтинга нет |
| Т9 | `Найдено только одно предложение: {магазин}, {итого} ₽ с доставкой.` | в выдаче одно предложение |

**Формулировки причин**

| Причина | Текст |
|---|---|
| самая низкая цена | `самая низкая цена с доставкой — {итого} ₽` |
| самая быстрая доставка | `самая быстрая доставка — {срок} дн.` |
| лучший рейтинг | `лучший рейтинг продавца — {рейтинг}` |
| лучшая гарантия | `самая длинная гарантия — {гарантия} мес.` |
| бесплатная доставка | `бесплатная доставка` |
| цена ниже среднего | `цена ниже средней на {N}%` |

## 6. Примеры

Данные условные, из примера расчёта в `benefit_index_draft.md`.

| Предложение | Итого, ₽ | Срок, дн. | Рейтинг | Гарантия, мес. |
|---|---|---|---|---|
| A | 47 990 | 2 | 4,8 | 12 |
| B | 46 200 | 5 | 4,5 | 6 |
| C | 49 500 | 1 | 4,9 | 24 |

**Пример 1. Режим по умолчанию, рекомендовано C (Т1 + Т4)**
Рекомендуем C: самая быстрая доставка — 1 дн., лучший рейтинг продавца — 4,9 и самая длинная гарантия — 24 мес. Оно дороже самого дешёвого варианта на 3 300 ₽ (7%), но по сочетанию цены, срока и надёжности подходит лучше всего.

**Пример 2. Пресет «Дешевле», рекомендовано B (Т3 + Т5)**
Рекомендуем B: самая низкая цена с доставкой — 46 200 ₽. Цена с доставкой на 5% ниже средней по остальным предложениям.

Проверка: среднее остальных (47 990 + 49 500) / 2 = 48 745; (48 745 − 46 200) / 48 745 ≈ 5,2%, округление до 5%.

**Пример 3. Пресет «Быстрее», рекомендовано C (Т2 + Т4)**
Рекомендуем C: самая быстрая доставка — 1 дн. и бесплатная доставка. Оно дороже самого дешёвого варианта на 3 300 ₽ (7%), но по сочетанию цены, срока и надёжности подходит лучше всего.

**Пример 4. Оценочная доставка (Т1 + Т6)**
Рекомендуем A: бесплатная доставка и лучший рейтинг продавца среди доступных предложений. Стоимость доставки оценочная.

**Пример 5. Нет рейтинга (Т7 + Т8)**
Рекомендуем F: предложение лучше всего сочетает цену, срок и надёжность продавца. Рейтинг продавца неизвестен.

**Пример 6. Одно предложение (Т9)**
Найдено только одно предложение: A, 47 990 ₽ с доставкой.

## 7. Запрещённые формулировки

- «Лучший на рынке», «гарантированно выгодно» и другие утверждения, которых нельзя доказать данными выдачи.
- Сравнение с площадками, которых нет в текущей выдаче.
- Скидка «до N%», если нет данных о прошлой цене.

## 8. Критерии приёмки

- [ ] Каждая рекомендация сопровождается объяснением
- [ ] В тексте не более трёх причин
- [ ] Числа в объяснении совпадают с таблицей
- [ ] Оценочная доставка и отсутствие рейтинга отмечаются
- [ ] Если рекомендация дороже самого дешёвого, это указано
- [ ] Для одного предложения выводится шаблон Т9
