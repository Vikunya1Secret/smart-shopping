# Требования к дашборду сравнения предложений

**Проект:** Умный Шопинг
**Функции:** M6.1 (таблица), M6.2 (сортировка), M6.3 (фильтры), M6.4 (карточка предложения)
**Связанные требования:** FR-9, FR-6, FR-8, NFR-1, NFR-5
**Автор:** Клейн А.Н.
**Дата:** 23.11.2026
**Статус:** требования для проверки реализованного; значения «предложено» согласуются с фронтенд- и бэкенд-разработчиками

## 1. Назначение

Дашборд показывает все найденные предложения в виде сводной таблицы, позволяет упорядочить и отфильтровать их и перейти к покупке. Критерий приёмки заказчика: «Дашборд сравнения отображает все предложения в таблице с сортировкой и фильтрами».

## 2. Состав страницы результатов

Сверху вниз:
1. Строка поиска с текущим запросом.
2. Блок рекомендации «Почему мы рекомендуем это» (M5.2, M5.3): лучшее предложение и объяснение.
3. Панель фильтров и сортировки.
4. Таблица предложений.
5. Топ-3 альтернативы выделены в таблице пометкой (предложено).

## 3. Таблица предложений (M6.1)

| Колонка | Содержимое | Примечание |
|---|---|---|
| Магазин | название продавца, источник | ссылка на карточку |
| Цена | цена товара, ₽ | |
| Доставка | стоимость доставки, ₽ | «Бесплатно» для 0; пометка «оценочно» при расчёте по тарифу |
| Срок | диапазон дней, например «3–5 дн.» | |
| Итого | цена товара плюс доставка, ₽ | основной показатель сравнения |
| Рейтинг | рейтинг продавца 0–5 | «нет данных», если отсутствует |
| Наличие | в наличии / под заказ / нет в наличии | |
| Индекс | индекс выгоды (0–1 или в процентах) | показывается, если включено в настройках (предложено) |

**Правила отображения**
- Рекомендованное предложение выделено визуально (рамка или фон) и не теряется при сортировке.
- Топ-3 альтернативы имеют пометку.
- Предложения «нет в наличии» отображаются внизу списка серым и не участвуют в рекомендации.
- Числа форматируются по правилам русской локали (разделитель тысяч пробелом, валюта ₽).
- Одинаковые товары из разных магазинов показываются как один товар с несколькими предложениями (результат склейки M3.4).

## 4. Сортировка (M6.2)

| Параметр | Направление по умолчанию |
|---|---|
| Индекс выгоды | по убыванию (**порядок по умолчанию**) |
| Итого | по возрастанию |
| Срок доставки | по возрастанию (по верхней границе диапазона) |
| Рейтинг | по убыванию |

**Правила**
- Повторный клик по заголовку колонки меняет направление.
- Текущая сортировка и направление отмечены в заголовке.
- При равных значениях порядок определяется итоговой ценой, затем названием магазина (стабильная сортировка, предложено).
- Предложения без значения (например, нет рейтинга) всегда в конце списка при любом направлении.
- Сортировка работает на любом количестве предложений выдачи (до 200, предложено) без перезагрузки страницы.

## 5. Фильтры (M6.3)

| Фильтр | Тип | Правило |
|---|---|---|
| Цена (итого) | диапазон «от» и «до» | границы включаются |
| Магазин | множественный выбор | список магазинов из текущей выдачи |
| Наличие | выбор | «только в наличии» включено по умолчанию |
| Срок доставки | «не более N дней» | сравнение с верхней границей диапазона |
| Рейтинг | «не ниже N» | значения 3, 4, 4,5 (предложено) |

**Правила**
- Фильтры комбинируются по условию «и».
- Рядом с таблицей отображается число показанных предложений («Показано 7 из 12»).
- Кнопка «Сбросить фильтры» возвращает исходную выдачу.
- Фильтры применяются без перезагрузки страницы; на время расчёта допускается индикатор.
- Фильтры не меняют рекомендацию: если рекомендованное предложение скрыто фильтром, блок рекомендации остаётся и показывает пометку «предложение скрыто фильтрами» (предложено).
- Состояние фильтров и сортировки сохраняется при переходе в карточку и обратно.

## 6. Карточка предложения (M6.4)

Открывается из строки таблицы (боковая панель или отдельная страница, на усмотрение фронтенда).

| Блок | Содержимое |
|---|---|
| Заголовок | название товара, магазин |
| Цена | разбивка: товар, доставка, итого |
| Доставка | стоимость, срок, пометка «оценочно» или «по данным магазина» |
| Продавец | рейтинг, число отзывов (M8.1) |
| Условия | гарантия (мес.), условия возврата; «нет данных», если источник их не отдал |
| Индекс | значения показателей и итоговый индекс (предложено) |
| Действия | «Перейти в магазин», «В избранное», «Следить за ценой» (последние две в рамках M7) |

**Правила**
- Кнопка «Перейти в магазин» открывает ссылку источника в новой вкладке.
- Недостающие данные отображаются понятной пометкой, а не пустым полем или нулём.

## 7. Состояния

| Состояние | Поведение |
|---|---|
| Загрузка | индикатор прогресса или скелетоны таблицы |
| Частичные результаты | строки появляются по мере ответа источников, сортировка пересчитывается |
| Пустая выдача | сообщение «Ничего не найдено», совет изменить запрос |
| Пусто после фильтров | сообщение «Нет предложений по выбранным фильтрам» и кнопка сброса |
| Ошибка | понятное сообщение без технических подробностей, кнопка «Повторить» |
| Источник недоступен | выдача из остальных источников; пометка «данные могли устареть» (M3.6, Should) |

## 8. Нефункциональные требования

- Сортировка и фильтрация выдачи до 200 предложений занимают не более 0,3 секунды (предложено).
- Первые результаты видны до окончания полного поиска; полное время ответа не более 10 секунд (NFR-1).
- Адаптивность: на узких экранах таблица заменяется списком карточек с теми же данными (предложено).
- Доступность: достаточный контраст, управление с клавиатуры, подписи у иконок.
- Новый пользователь находит товар и получает рекомендацию за 3 минуты (NFR-5).

## 9. Критерии приёмки

- [ ] Таблица содержит колонки: магазин, цена, доставка, срок, итого, рейтинг, наличие
- [ ] Сортировка работает по цене, сроку, рейтингу и индексу выгоды в обоих направлениях
- [ ] Фильтры по цене, магазину, наличию, сроку, рейтингу работают по отдельности и вместе
- [ ] Рекомендованное предложение выделено и видно при любой сортировке
- [ ] Карточка показывает детали, возврат, гарантию и открывает магазин по ссылке
- [ ] Отсутствующие данные не ломают отображение
- [ ] Состояния загрузки, пустой выдачи и ошибки отображаются корректно
- [ ] Предложения «нет в наличии» не рекомендуются
