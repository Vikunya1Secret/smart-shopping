## 5. Принятые решения

| Дата | Решение | Основание |
|---|---|---|
| 16.11 | при склейке действует принцип «лучше пропустить, чем склеить разные товары» | критичность ложных склеек для пользователя |
| 16.11 | расчёт доставки: приоритет данным магазина, затем тарифная таблица, затем значение по умолчанию с пометкой «оценочно» | отсутствие подтверждённых API служб доставки |
| 16.11 | индекс выгоды в MVP строится на прозрачной весовой модели с четырьмя весами и тремя пресетами | требование отчёта 1; сложная модель отнесена к Could |

Все значения (веса, коэффициенты зон, пороги) предложены аналитиком и ожидают согласования с бэкенд-разработчиком.
